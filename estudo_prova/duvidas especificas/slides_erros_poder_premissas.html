Questão 1 Tipos de erro

Erro tipo I e erro tipo II

O teste só decide rejeitar ou não rejeitar H0, sem saber se H0 é verdadeira. Cada decisão pode estar errada.

Tipo I · falso positivo

Rejeitar H0 quando ela é verdadeira.

α = P(rejeitar H0 | H0 verdadeira)
  • α é o nível de significância, escolhido antes do experimento (ex.: 0,05); 1 − α é a confiança.
  • Fácil de controlar: depende só da distribuição sob H0.
  • Analogia: o alarme toca sem fogo.
Tipo II · falso negativo

Não rejeitar H0 quando ela é falsa.

β = P(não rejeitar H0 | H0 falsa)
  • Depende do valor real do parâmetro (tamanho do efeito): quanto menor o efeito, maior β.
  • Difícil de controlar, porque esse valor real é desconhecido.
  • Analogia: há fogo e o alarme fica mudo.
H0 é verdadeiraH0 é falsa
Não rejeitar H0Correto (1 − α)Erro tipo II (β)
Rejeitar H0Erro tipo I (α)Correto (1 − β, poder)

Questão 2 Poder do teste

Poder (1 − β): a chance de detectar um efeito que existe

Significado

Probabilidade de o teste rejeitar H0 quando H0 é falsa.

1 − β = P(rejeitar H0 | H0 é falsa)

Mede a sensibilidade do teste aos efeitos que violam H0.

  • Como ler: poder = 0,80 significa que, se o efeito tiver o tamanho planejado, o teste o detecta em 80% das vezes; nos outros 20% (β) ele passa despercebido.

Não confunda: 1 − α é a confiança (acertar quando H0 é verdadeira); 1 − β é o poder (acertar quando H0 é falsa).

α: curva de H0 na região de rejeição β: curva real na região de não rejeição 1 − β: curva real na região de rejeição

Questão 2 Do que o poder depende

O que muda o poder, e como isso define o n

  • Efeito maior → poder ↑não controlávelDiferença entre o valor real e o de H0
  • Variabilidade (σ) maior → poder ↓não controlávelDispersão natural do processo
  • α maior → poder ↑controlávelÀs custas de mais falsos positivos
  • n maior → poder ↑controlávelA alavanca principal no planejamento

δ*, o efeito minimamente interessante: escolhe-se o menor efeito que importa e calcula-se o poder para ele. Esse poder é um piso, porque efeitos maiores que δ* terão poder maior. É assim que se define o tamanho amostral, antes do experimento.

Exemplo da aula: pacotes de componentes

Detectar um desvio de −1% em 50 kg (δ* = 0,5 kg), com σ ≈ 1, α = 0,01.

# poder com a amostra atual
power.t.test(n = 10, delta = 0.5, sd = 1,
             sig.level = 0.01, type = "one.sample",
             alternative = "one.sided")
          power = 0.1654013

# n necessário para poder 0,85
power.t.test(power = 0.85, delta = 0.5, sd = 1,
             sig.level = 0.01, type = "one.sample",
             alternative = "one.sided")
              n = 47.98044

Com n = 10 o poder é só ~17% (β ≈ 0,83). Para chegar a 0,85 são necessárias pelo menos 48 observações.

Questão 3 Premissa de normalidade

Verificar normalidade: teste de Shapiro-Wilk

✓ Resposta: teste de Shapiro-Wilk

H0: a amostra vem de uma população Normal
H1: a amostra não vem de uma população Normal
  • A aula lista três opções (escolher só uma): Shapiro-Wilk, Anderson-Darling e Kolmogorov-Smirnov. O Shapiro-Wilk é o mais utilizado e o adotado na disciplina.
  • Rejeitar H0 (p < α) = evidência de que os dados não são normais.
  • Sempre combinar com a análise gráfica (QQ-plot). Na ANOVA, testa-se a normalidade dos resíduos.
> shapiro.test(my.sample)

 Shapiro-Wilk normality test

data: my.sample
W = 0.88086, p-value = 0.1335

> car::qqPlot(my.sample)   # apoio gráfico

p = 0,13 > 0,05 → não rejeitamos a normalidade. Aqui, não rejeitar é o resultado que queremos.

Lembrete da Aula 06: o teste t é robusto a violações leves ou moderadas da normalidade.

Questão 4 Premissa de independência

Autocorrelação serial: teste de Durbin-Watson

✓ Resposta: teste de Durbin-Watson

  • Detecta autocorrelação serial nos resíduos: observações vizinhas parecidas entre si, por exemplo por aquecimento ou desgaste de equipamento.
  • Depende da ordenação. Os dados devem estar na ordem que gera a suspeita (ordem de coleta, posição, etc.).
  • Não existe um teste de independência propriamente dito. A independência é garantida no planejamento (aleatorização, sem pseudorreplicação); o D-W só flagra tendências ligadas à ordem.
  • Violar a independência costuma ser o problema mais difícil de corrigir.
> library(car)
> durbinWatsonTest(lm(my.sample ~ 1))
 lag Autocorrelation D-W Statistic p-value
   1      -0.0848535      2.111733    0.864
 Alternative hypothesis: rho != 0

H0: ρ = 0 (sem autocorrelação). p = 0,86 → sem evidência de autocorrelação.

Complemento (não está nos slides): a estatística D-W vai de 0 a 4. Perto de 2 indica ausência de autocorrelação; perto de 0, autocorrelação positiva; perto de 4, negativa.
